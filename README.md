## Structure

- `index.html`, `styles.css` — root CV site
- `dev/` — engineer resume page
- `devrel/` — DevRel resume page
- `images/` — site images
- `CNAME` — custom domain (pablodevrel.com)

Website assets only — job-search workspace and private material live in a separate private repo.
